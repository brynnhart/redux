# LoRD UX Reference

This document describes how original LoRD screens behave.

## General principles

LoRD screens are:

- sparse
- menu driven
- vertically stacked
- prompt driven

Screens do NOT use modern UI layouts or large bordered boxes.

## Prompt rhythm

Typical prompt pattern:

Your command, Player? [12:34] :

The timer increments every second.

## Menu style

Menus are displayed inline:

(F)orest
(K)ing Arthurs Weapons
(H)ealers Hut

Commands are single letters.

## Status display

Status is typically shown as one compact line:

HitPoints: (21 of 21)  Fights: 15  Gold: 688  Gems: 2

## Screen density

LoRD uses relatively dense screens with minimal padding.

## Visual separators

Common separators:

------------
=-=-=-=-=-=-=
*****

## Tone

Tone is irreverent, humorous, and occasionally crude.

Examples:

- PvP kill quotes
- bard songs
- sarcastic NPC comments
